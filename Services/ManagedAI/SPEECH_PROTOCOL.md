# 托管语音网关（开发原型）

本机回环原型，不是已部署服务。真实服务商账号、产品身份签发、费用控制、TLS 部署、跨实例限流、持续计费上限和实际语音验收均未完成；不能直接用于公开运营。客户端不内置或读取服务商密钥。默认运行器只监听 127.0.0.1，不能通过更改监听地址直接作为生产服务。

客户端连接 `/v1/speech/stream`，使用 `Authorization: Bearer <用户会话令牌>`。发送 `{ "type": "start", "source": "en", "target": "zh" }`，等待 `{ "type": "ready" }` 后发送二进制 16kHz、单声道、有符号 16 位小端 PCM；推荐每包 2560 字节（80ms），服务端单包上限 6400 字节。结束发送精确文本 `{"type":"finish"}`；取消直接关闭连接。收到的 `source`、`translation` 事件有 `text`、`segment`、`final`。两种流的段号各自递增，**不保证可直接按号配对**；上游文本是增量还是完整重写，官方文档没有给出明确可依赖语义，必须用真实服务确认，不能凭模拟测试声称兼容。其他事件是 `ready`、`finished` 或无敏感信息的 `error`。任何通信都不记录文本或音频。

上游固定到官方 AST 2.0 地址，密钥仅由网关环境变量 `MORIQ_SPEECH_PROVIDER_KEY` 提供。本机原型可通过 `MORIQ_ACCOUNT_DB` 使用与 AI 网关相同的 AccountStore：新连接在连接上游前检查有效会话并扣除一次每日请求额度，向上游发送音频前按向上取整的整秒原子扣除该账户的每日音频额度；未设置音频额度时不转发音频。进行中的连接定期检查撤销和过期，数据库异常时拒绝或终止连接；单次会话音频量和墙钟均最多 30 分钟，连续 5 秒没有客户端数据会关闭会话。音频秒数不等于实际账单，仍需接入供应商用量和费用上限、全局预算与跨实例并发控制。仅用于测试的替代方式是 `MORIQ_SPEECH_TOKEN_HASHES` 的逗号分隔 SHA-256 哈希，两种方式不能同时使用；该测试方式不实施账户额度。账户注册、令牌签发和产品账户体系尚不存在；无需在客户端放置固定令牌或上游凭据。

协议依据 [AST 2.0 官方文档](https://docs.volcengine.com/docs/doubao-voice/simultaneous-interpretation2-0-api-access-documentation?lang=zh) 及其页面提供的 Python 示例 protobuf；2026-11-12 下载的官方示例 SHA-256 `b8184a650c4bc7599ea9a1ae3fbba40fdc0d88c14ac9f386c10ca83192033f09`。测试使用该示例的生成类解析本实现的 start/audio 请求，及序列化真实 schema 的响应后由本实现解码。官方示例仅供协议交叉检验，没有打包进产品。

`Tests/ManagedSpeech/run.sh` 启动 Swift 客户端、回环网关和独立模拟上游，验证音频转发、字幕事件与结束、错误账户拒绝、SQLite 每日请求额度阻止新上游会话、音频额度阻止超额音频转发、会话过期及撤销后在无后续音频的情况下关闭上游；所有令牌及音频均为虚构，未连接真实服务，未验证质量、延迟或平台计费。依赖 Python 的 `websockets` 16；产品服务器的依赖需要锁定并独立部署。

## 本机应用桥接（受限原型）

仅当 `MORIQManagedSpeechEndpoint` 明确配置、账户会话存在、用户在设置启用系统音频发送授权时才连接；缺少条件、连接中断或撤销授权时停止采集并显示原因，不静默回退。`ManagedSpeechAudioBridge` 在屏幕录制音频回调中转 16kHz PCM16、80ms 分包，发送队列满时停止而非静默丢包。2026-11-12 使用合成英文对真实上游测试，观察到原文和译文 partial 各自为增量、final 为本段完整文本；客户端现分别拼接两条流并以 final 校正。由于不能从该单一样本推断原文和译文的段号必然一一对应，当前不会把译文按未经验证的段号绑定到原文历史，且仍需更多语言、长句、网络断线与不同说话人实测。

隔离测试 `Tests/ManagedSpeechSystemAudio/run.sh` 只捕获测试进程自身播放的合成声音，实际经 ScreenCaptureKit、PCM 转换、Swift 客户端、回环网关和模拟上游得到双语最终事件；`Tests/ManagedSpeech/run.sh` 覆盖 48kHz 合成采样转换、账户令牌拒绝、断线关闭上游与授权监测回调。测试没有连接真实上游；单独的授权撤销通知测试不等于已验收实际应用的整条撤权路径。

`Tests/ManagedSpeech/real_upstream.py --run` 是需显式启动的真实服务烟测：仅发送 4.2 秒本机合成英文，服务凭据从钥匙串读入内存，不记录到日志或磁盘；配合 `--swift-client` 实测 Swift 客户端→回环网关→官方服务，收到 22 个原文、15 个中文增量，最终包含会议、下午三点及中午前提交报告等关键信息。真实请求有服务费用，不能默认纳入自动化回归，也不代表服务已对公众上线。此机器的 Python 默认未配置 CA 路径，网关使用已安装的 certifi CA 包并保持 TLS 校验证书；未来服务器需锁定并验证 CA 包及依赖版本。
