# 统一 AI 服务：本地协议原型

当前应用默认仍使用本机个人凭据；本目录是仅供本机联调的服务端原型，**尚未部署，不能用于公开运营**。应用已预留显式构建配置：仅当 Info.plist 提供 `MORIQManagedAIEndpoint` HTTPS 地址时，助手和截图 AI 才使用账户会话令牌；没有配置时维持原有连接，配置无效时直接报错，不向其他地址回退。真实登录与令牌发放尚未实现，当前不应在发行构建中启用该配置。服务端严格只监听回环地址，不接受外部客户端。不要将真实用户或模型密钥放入测试代码、安装包、日志或版本库。

## 本地验证

从项目根目录运行 `Tests/ManagedAI/run.sh`。测试自动启动本机模拟模型服务和网关，使用临时虚构令牌及合成图像验证 Swift 流式读取、两回合共 22 张图、账号缺失/过期、上游错误、客户端取消、服务端固定模型、拒绝远程图片和重定向、限流；不连接外部网络。`MORIQ/ManagedAIClient.swift` 使用钥匙串保存个人账户令牌，正式构建只接受 HTTPS；HTTP 回环例外只在 Debug 测试启用。

网关从服务端环境获取上游 URL、模型名和密钥，以及账户令牌 SHA-256 到账户 ID 的映射。令牌应由可信身份服务使用安全随机数为每个账户生成、传输和撤销；不能将任何通用账户令牌或上游密钥预埋在应用里。网关忽略客户端给出的模型名，限制请求体、文本和图片大小，阻止图片远程 URL；它只转发字节流，不记录用户对话或图片。网关和客户端都拒绝重定向，避免凭据被带往其他地址。

本地原型还可通过 `MORIQ_ACCOUNT_DB` 选择 `AccountStore` 的 SQLite 账户数据。它保存不含用户内容的账户标识、会话令牌哈希、到期与撤销状态及按 UTC 日的请求计数；只接受当前用户可读写的普通文件（新文件权限 0600）。`put_account`、`add_session`、`revoke` 为未来可信身份服务提供调用入口，`add_session` 只接收令牌哈希。每次消耗配额时使用事务重新检查会话，配额在进程重启后保留；数据库异常时网关拒绝请求。每日额度按请求数计，在请求格式校验及上游调用之前消耗，因此失败请求也会计数；它不是按 token 或实际费用计算的账单。每分钟限流仍只在单进程内生效。不要把这一 SQLite 原型当成多区域、高可用或完整防滥用方案。

## 距离正式服务的缺口

需要先选择服务器、模型服务和运维方式，搭建用户注册登录及安全发放/撤销会话、持久化账户与配额、跨实例限流和成本控制、监控告警、隐私政策与删除机制，配置 TLS、超时及故障恢复，再进行安全审计和部署后的真实流式、图像能力、并发及移动网络验收。本地示例只有进程内简易限流，不提供上述设施；不能通过简单解除回环绑定来上线。截图类请求会将用户提交的图片发送给所配置模型服务，实际产品应明确披露接收方与数据处理方式，图像理解能力也必须通过实际模型验收，不能由接口格式推断。

客户端取消的本地测试验证了调用方能及时停止等待；网关在上游长时间不再产生数据时，是否能立即关闭上游和停止计费尚未验证，正式实现需补端到端取消、断线和资源回收测试。真实账号、服务地址和模型未配置，模拟测试不能证明任何生产服务可用。
