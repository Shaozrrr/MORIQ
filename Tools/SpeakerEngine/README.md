# 实验性流式说话人引擎

此辅助进程使用 FluidAudio 固定提交 `d653a34a620c013febd7530427b4963ae18064b2` 的 Sortformer 实现，FluidAudio SDK 为 Apache-2.0；模型权重有独立许可证，FluidAudio 模型转换页与 NVIDIA 上游权重页的标记不同，发行前须确认整个授权链并随包提供必要声明。此目录仅实现引擎协议，不代表模型或应用已获准发行。

辅助进程只接受已存在的本机 Core ML 模型路径，从标准输入接收 16 kHz、单声道、Float32 小端 PCM，以 JSON 行输出匿名槽位和相对会话的 16 kHz 样本范围；不会采集音频、下载模型、保存声纹或推断真实姓名。每个音频源应各自拥有独立实例；音频中断或丢块时必须终止当前实例，不能静默跳过并继续使用偏移。当前尚未接入应用，模型文件的完整性校验、发行打包及 Intel 实测均未完成。

`Tests/SpeakerEngine/run.sh` 使用公开中文四人音频与 FluidAudio 官方 CLI 的结果做逐段比较，并检查桥接过载后的失败处理。2026-11-13 本机 arm64 运行 16 个最终片段与官方 CLI 槽位及时间一致；并非人工标注真值，不能用来宣称说话人识别准确率，也没有验证实时端到端延迟或真实姓名识别。
