# 验收测试和重现步骤

## S01 品牌与 UI
[ ] App 菜单栏/设置/系统通知统一 MORIQ，没有旧 ScreenBuddy 字样。
[ ] 主窗口只含五功能配置，没有文件上传/固定演示区/多余大卡片。
[ ] 五项“演示”分别弹出，不共用不相关的动画。
[ ] 每个演示区右上有且仅有「↻ 重新播放」，标题栏右上关闭；无底部说明条。
[ ] 重播中途再重播不会发生双动画叠加；Esc 可关闭。
[ ] 系统深浅主题、1x/2x 缩放、Reduce Motion、VoiceOver、动态字体可用。

## S02 功能开关与进程
[ ] 关闭设置窗，功能仍可用；菜单栏可再次打开。
[ ] 关闭单项功能，所有对应观察器/计时器/浮窗/快捷键停用。
[ ] 重启后开关和快捷键保持一致；权限拒绝后状态不会虚假显示可用。
[ ] 菜单栏“暂停全部”不会误删用户历史；退出后无残留后台进程。

## S03 转换圆盘
[ ] Finder 中拖 HEIC 时 Shift 打开，松手 PNG 保存真实文件；原 HEIC 不变。
[ ] 多选 3 个文件批处理；损坏文件报单项错误；命名冲突不覆盖。
[ ] 转换期间 Finder 不冻结；Esc/放弃拖拽不写输出；无权限能有正确提示。
[ ] 三屏及异构缩放下圆盘不越界；触控板/鼠标均可。

## S04 AI 助手
[ ] `⌘ ⇧ Space` 从 Safari/IDE/全屏唤醒底部胶囊；Esc 恢复工作焦点。
[ ] 没 API Key 不能假流式回复；错误密钥/超时/429 均可说明并重试。
[ ] 屏幕截图未明确附加且确认时，不向模型发送图片数据。
[ ] 持续感知停止后不再生成新的截图请求；睡眠/锁屏也停止。

## S05 暂存架
[ ] Finder 文件拖至边缘 → 展开 → 释放成功 → 再拖出邮件/文件夹。
[ ] 原始文件未移动/删除；删除原文件后失效提示正确。
[ ] 屏幕切换、重启应用、右侧贴边、自动收起/手动唤出不闪烁。

## S06 剪贴板
[ ] 复制文本/图/链接记录并能搜索和复制回去。
[ ] 临时/隐私标记与用户排除 App 不入库；关闭功能后不再读取剪贴板。
[ ] 无辅助功能权限时只复制到剪贴板，不谎称已自动粘贴。
[ ] 清除历史后磁盘存储不再返回原记录（并说明数据库可能需要 vacuum/加密设计）。

## S07 超级截图
[ ] `⌘ ⇧ X` 框选真实屏幕；副显示器坐标正确；截图内容可复制/保存。
[ ] OCR 真实返回中英混排；无文字明确提示；自动取消/超时正确。
[ ] 可用语言包时英文译中文、中文译英文真实输出；语言不可用提示下载/切换。
[ ] 标注合成保存；马赛克不可恢复；贴图置顶可拖动/关闭。
[ ] “问 AI”必须先预览并明确确认附加截图；模型不支持图像有说明。

## S08 安全与发布
[ ] ZIP 解压的 ../ 与软链逃逸测试、异常大压缩包被阻断。
[ ] API Key 仅存 Keychain，网络及系统日志不包含它。
[ ] Xcode Release build 成功，签名/公证与目标分发流程验证。
[ ] 第三方许可证报告包含具体 SHA、依赖、使用范围。
