# 实施计划（按可验证成果交付，不是假 Demo）

## 里程碑 M0：工程与资产（独立可编译）
建立 Xcode 项目、Bundle ID、权限说明、单一 `AppCoordinator`、菜单栏、5 项设置配置、品牌名 MORIQ。将 `06_BRAND` 引入 Assets.xcassets，选择统一的主图标。交付实际运行录屏/截图和编译日志。不要复制旧 ScreenBuddy 工作台布局。

## M1：UI 与五项演示（不会读用户文件）
实现真实 NSWindow 设置界面：五行功能和切换；各点击“演示”弹独立窗口；五条动画各自状态机；重播在动画区域右上角、只有一个重播按钮、无底部文本。品牌开场动画只能用于首次介绍/关于页面，不得强制每次播放。系统 Reduce Motion、深浅模式和窗口大小测试。

## M2：系统底座
全局快捷键注册/注销、冲突提示；浮窗控制/焦点保存恢复；多显示器与全屏空间；权限协调器和操作任务队列。交付 3 种系统快捷唤窗的真实测试。

## M3：圆盘 + 文件暂存
按 F01 文档先实现 4 种图片格式的真实转换，再扩展可用格式；临时文件、命名冲突和保存行为测试。按 F03 实现文件暂存与拖出、贴边和多屏支持。提交真机视频展示 Finder 文件确实被转换并保留原始文件。

## M4：超级截图 + 翻译
区域截图、保存/复制、Vision OCR、Translation 翻译、原文译文卡、基本标注与置顶贴图、问 AI 的上下文入口。确保非英文语言识别和翻译语言包不足时反馈正确；复杂原位覆盖翻译列为后续增强验收，不阻塞基础截图翻译发布。

## M5：AI + 剪贴板
原生底部胶囊、BYOK Keychain、流式回复、选区附加及明确上传确认；剪贴板历史、搜索、敏感过滤、回写剪贴板和可选自动粘贴。权限与取消测试。

## M6：发布级打磨
签名、公证、安装/卸载、登录项、系统升级、多显示器和全屏回归；连续 8 小时空闲监测、剪贴板持续复制、批量转换压力、热键冲突、权限拒绝；固定所有依赖版本/许可证、更新说明/用户帮助、异常日志管理。

## Codex 协作方法
每个里程碑单独分支/PR。实现前写 3–8 项具体验收；代码提交必须有编译输出；如没有 macOS 实际设备/SDK，明确说明无法验证并交付源码与可复现测试步骤，绝不声称已经成功运行。把未完成工作写在 `KNOWN_GAPS.md`。不得把演示动画完成等同于功能完成。
