# F04 智能剪贴板

## 真实流程
复制一段话 → 复制一张图 → `⌘ ⇧ V` → MORIQ 浮动搜索面板出现在当前桌面 → 输入“会议” → 上下键选择复制记录 → Enter 将其重新放入系统剪贴板（如用户开启自动粘贴且获权限，可再粘贴进原应用）→ 面板收起。选记录同时可“去格式复制、收藏、删除”。

## 技术
- 阅读 Maccy `Maccy/Clipboard.swift`：用 `NSPasteboard.general.changeCount` 及默认 ~0.5s 的计时器检测变化，只读新增记录。支持 `.string`, `.html`, `.rtf`, `.png`, `.tiff`, `.fileURL`，注意粘贴时多格式一致性。
- 对 `concealed/transient/autogenerated` 类型优先过滤；指定 App 的 Bundle ID、正则敏感模式可加入排除名单；密码管理器还应加入预设排除（需告诉用户这是尽力而为，无法保证识别全部敏感数据）。
- 存储用本地 SQLite/SwiftData，给定容量/条目数上限；大图缩略图异步处理；历史可一键清空/暂停，数据不上传。
- `CGEvent` 自动注入 Cmd+V 涉及辅助功能权限；**不获得权限时先实现“重新复制到剪贴板，用户手动粘贴”**，不能误称自动粘贴完成。
- 已从自身写入剪贴板的数据应去重/标识来源，避免循环无限追加；监测应用焦点变化后恢复原应用。

## 权限、性能、异常
定时器仅在开关开启时运行；睡眠后恢复检测 changeCount 是否重置。大文本、重复复制、复制文件 URL、图片和空字符串需测试。不存储粘贴密码或密钥的完整值到日志。`⌘ ⇧ V` 与现有系统/软件快捷键冲突时提供自定义组合键。

## UI
小型黑色列表浮窗，上方搜索框下方最近记录，行显示“图标、内容摘要、来源 app、时间”，支持热键和鼠标。打开/关闭 200ms 内，不要占满屏幕。可设置默认历史上限，例如 1000 条（只是初始配置，需性能验证）。
