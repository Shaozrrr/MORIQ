# F05 超级截图（含翻译）

## 一条完整的真实体验
用户在网页看英文文章 → `⌘ ⇧ X` → 光标变十字、屏幕暗化 → 框一段英文 → 选区附近浮出工具条 `[复制][OCR][翻译][标注][贴图][问 AI]` → 点“翻译” → 本地 Apple Vision 提取文字 → 检查 Apple Translation 是否支持英译中与所需语言包 → 得到译文后在旁边展示原文/译文 → 可以复制、切换语言、关闭 → 返回原网页继续工作。

## ① 截图捕获
- 优先 ScreenCaptureKit (`SCShareableContent`, `SCScreenshotManager`/适用版本 API)；按系统版本选择安全的实现与回退路径，屏幕访问权限需用户明确授予。
- macshot `macshot/Capture/ScreenCaptureManager.swift` 使用短时缓存 pre-warm 截屏共享信息、处理瞬态菜单与焦点回退，注意不要未经授权缓存屏幕内容。
- 多屏幕坐标空间、显示缩放、旋转屏、HDR/sRGB 色彩、鼠标光标是否包含、后台悬浮窗是否被截图都要逐项验证。截取到的图像按需在内存短暂存放，退出后释放。
- 截图可以复制到 NSPasteboard / 保存到用户指定位置；不默认上传到服务端。

## ② OCR
- 使用 Apple Vision `VNRecognizeTextRequest` 或 macOS 15+ 的较新 `RecognizeTextRequest`，`recognitionLevel=.accurate` 作为质量优先默认，提供快速模式优化路径。
- `macshot/macshot/Services/VisionOCR.swift` 核验：支持按系统首选语言配置识别语言，对中英文混排不要只选英文。OCR 每个文本块保存 bounding box、文本、置信度、读取顺序。
- 文字识别操作含 10s 等待/取消兜底；没有识别出文字则明确提示可复制原图，不能返回空白成功弹窗。

## ③ 翻译
- 首选 Apple Translation（macOS 15+）；检测可用语言对、系统语言包状态、是否需要下载资源以及调用可能受平台授权/可用性约束。不要写死所有语言离线均可用。不能离线时给出“下载语言包/选择其他引擎”明确行动。
- 引擎协议：`TranslationEngine.availableLanguages`, `availability(from,to)`, `translate(text,from,to)`, `cancel`。优先本地；BYOK 云翻译为用户可选回退，发送前说明将传输什么文本到哪个提供商。
- 结果卡由“语言切换、原文、译文、复制、关闭”组成，显示在选区附近，不挡住选区最重要部分；长文本滚动。支持混排保留段落结构，不承诺表格、漫画、手写体自动完美排版。
- **原位覆盖翻译**属于进阶阶段：根据 OCR bbox 用字体测量排版，将背景区域简单填充/修复后叠加译文；优先浅色纯背景；复杂图像提供普通译文卡，不能声称完整修复背景。

## ④ 标注
- SwiftUI Canvas/Core Graphics 绘制路径、箭头、矩形、文字、马赛克，支持撤销重做；导出应在独立渲染层合成，不破坏原始截图。马赛克必须真正不可逆遮盖，不能只是 UI 毛玻璃效果导致敏感信息可还原。

## ⑤ 贴图
- 截图缩略图一键成为独立 `NSPanel` 浮窗；可拖动、缩放、透明度调节、关闭、复制、保存；多屏幕的位置有恢复兜底。

## ⑥ 问 AI
- 触发后将选定截图作为待附加项交给 AI 助手，用户看清范围并确认才发送。模型不支持图片则禁用此操作并解释原因。可先 OCR 再选择仅发送文字。

## 失败与验收
- 屏幕捕获权限拒绝：显示系统设置打开方法，不能假装成功。
- OCR 无字：显示“未识别到文字”。翻译包缺失：可下载或切换引擎。网络失败：留住原文与截图，支持重试。鼠标拖出边界/在副显示器框选：裁剪坐标正确。
- 目标验收：截图后可真实本地 OCR；英译中、中文译英在可用语言包/选定引擎情况下可真实输出；复制结果可回到原 App 粘贴；关闭开关后解除捕获热键。
