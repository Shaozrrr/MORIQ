# MORIQ V1｜正式产品需求 PRD

## 1. 用人话描述产品
装好 MORIQ 后，Mac 菜单栏多一个小图标。平时不占屏幕、不常驻大窗口。你在 Finder 拖文件想转格式时按 Shift，鼠标旁出现轮盘；你看到一段外语想译成中文就按截图快捷键；想问屏幕问题按 `⌘ ⇧ Space`，屏幕下方弹出一个小 AI 胶囊；文件暂放屏幕边缘；复制过的内容随时搜索。不用切回 MORIQ，不用上传到一个网页。

## 2. 目标用户与问题
面向日常用 Mac 写作、开发、设计、工作/学习的个人用户。他们需要频繁解决小任务：HEIC 转 PNG、截图转文字、英语屏幕翻译、临时转移多个文件、找回复制过的内容、问屏幕上的报错。核心价值是减少离开当前工作场景的次数。

## 3. 首版范围：恰好五个功能
- F01 万能转换圆盘：Finder 中系统级拖拽触发，真实格式转换与批量操作。
- F02 AI 助手：全局快捷键唤醒、BYOK、当前屏幕授权、选区与连续问答。
- F03 文件暂存架：屏幕边缘收纳、预览、拖回、跨会话恢复。
- F04 剪贴板：文本/图片/链接历史、检索、收藏、隐私过滤、可选粘贴。
- F05 超级截图：区域与窗口截图、OCR、翻译、标注、贴图、问 AI。

## 4. 不做什么
不做云端账户、跨平台同步、平台代付 AI Token、AI 24 小时屏幕追踪、Web 上传主页、重型视频剪辑、自动点击任意软件的万能 Agent；复杂 OCR 原位排版重绘不作为首发基础验收。不得悄悄扩大范围。

## 5. 核心成功故事
**故事 A：文件转换**：用户在 Finder 选中 3 张 HEIC → 拖起 → 按 Shift → 圆盘只显示兼容目标格式 → 指向 PNG → 松开 → 在原目录生成有避免重名处理的新文件 → 旧文件保留；不支持的文件提示跳过原因。

**故事 B：翻译屏幕**：用户在浏览器读英文报告 → `⌘ ⇧ X` → 框住一段 → 选“翻译” → 在选区附近看到原文/译文 → 复制译文 → 自动回到报告。离线语言缺失时提示下载/等待，不能假装翻译成功。

**故事 C：AI 解释代码报错**：用户在 IDE 按 `⌘ ⇧ Space` → 底部胶囊展开 → 点击“读取当前选区”或“附加截图” → 确认发送哪些内容 → 模型流式解释 → 用户继续问 → Esc 收起 → IDE 保持可操作。

**故事 D：暂存文件**：用户从下载文件夹拖 4 份资料靠近右侧边缘 → 暂存架磁吸展开 → 放入 → 切换到邮件/聊天 → 从边缘拖出 → 资料仍存在原目录。

**故事 E：找回复制内容**：用户复制一段文字又复制别的内容 → `⌘ ⇧ V` → 搜索关键字 → Enter 复制/按授权粘贴 → 返回原应用；密码管理器数据不被存储。

## 6. 首次启动与设置生命周期
第一次打开：轻量欢迎页 1 屏说明“这些工具直接在桌面工作”；每项默认状态和权限清楚说明；主界面五行。屏幕捕获、辅助功能、文件访问均在第一次需要对应能力时才申请。全局热键冲突时显示冲突提示并允许更改。菜单栏始终有“打开设置 / 暂停全部 / 退出”。关闭设置窗口并不退出 App；真正退出时必须取消事件监听和定时器。

## 7. 所有界面文本必须中文
不要留下 Converter、Shelf、Clipboard 等英文菜单标题；保留技术名词格式如 HEIC/PNG/API Key/macOS。错误信息采用“发生了什么 + 如何恢复”，例如“这张图尚无法转换为 AVIF，请选择 PNG 或 JPG”，不允许“未知错误 0x01”。

## 8. 价值取舍
V1 各功能都要可用，不以五个精美 Demo 冒充 V1；若时间紧，明确交付优先级和真实已支持格式，禁用尚未实现的选择项。允许拆成迭代，但禁止宣称未开发的功能完成。商业化收费、云账号、更新机制属于后续独立决策。
