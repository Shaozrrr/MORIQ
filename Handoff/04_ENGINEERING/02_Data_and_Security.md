# 数据、隐私、打包、依赖许可证与威胁清单

## 保存内容和位置
- `UserDefaults/AppStorage`：五个开关、快捷键、动效偏好、语言、允许本地恢复会话标记。
- `Keychain`：API Keys、必要的持久机密，不写进 plist/SQLite/日志。
- `Application Support` 下的本地 SQLite/SwiftData：剪贴板历史/收藏（可设置定期清理）、AI 聊天历史（默认可选）、暂存架文件引用、操作任务的最少元数据。
- 缓存目录：截图缩略图、临时转换输出，缓存生存期有限；原始用户屏幕图和剪贴板内容不能自动用作产品分析数据。

## 安全边界
**截图**：屏幕权限授权只是操作系统级批准，不意味着用户允许内容上传给模型。用户在截图/选区预览中明确知道要上传哪部分、发送给哪个模型。持续感知的开关、停止按钮、发送次数限制要清楚。

**转换**：不覆盖原件；输出路径先校验再写；临时文件在受控目录；仅信任可解析的 URL/UTType，不能用扩展名当唯一真值。解压 ZIP 验证路径穿越和总展开大小限制；处理恶意输入不执行任意命令。

**剪贴板**：排除 `.concealed`, `.transient`、密码管理器或用户选定 App；剪贴板意外包含 token/密码时用户有一键删除/暂停，不上传。不要假设正则检测可覆盖所有隐私。

**AI**：对用户所选模型站点的 HTTPS 通信有明确文案；敏感信息不记录完整请求正文到日志；只输出消敏日志与随机请求标识。任意模型输出不应直接当作系统命令执行，工具调用需要用户批准危险文件操作。

**授权与发行**：每个引用到的 GitHub 项目在引用其代码前由开发者保存所依赖具体 commit SHA、LICENSE、第三方依赖许可证及 NOTICE；若不能确定许可证允许商用再发布则先自行重写，不直接带入源码。FFmpeg 编码器、GPL/LGPL 选择、再分发字幕/专利方面需单独做发行核查。

## 产品合规
- 不承诺任何软件商标/Logo 名称已经完成商标注册或域名独占；MORIQ 需正式搜索本地及目标销售地区的商标、App Store 重名与域名。
- 原稿是位图参考，不存在已经验证的 SVG vector master；生产图标需设计师精修轮廓并从同一个 SVG 导出，保证品牌一致性。
- 每个 3P 库采用固定版本；自动更新需有回退策略；App 签名/公证/安装包发行取决于 Apple 开发者账号和分发渠道。

## 容错规则
每个操作至少有 `idle/running/success/failure/cancelled/permissionRequired` 状态。错误要可解释且可重试；任务被取消不报“成功”；任务开始后用户关闭设置窗口不能销毁关键服务；系统睡眠/退出时中断并清理临时文件；不无限重试。
