# MORIQ 视觉系统与全部界面规格

## 品牌资产
主标识为黑色/蓝色环形抽象图形；完整英文名 **MORIQ**，全部大写；禁止再出现 ScreenBuddy 字标。菜单栏一律使用从单色图标导出的 template 图，不能在菜单栏里硬塞亮蓝。主 Logo 不允许强行替换成纯色方形或充满金属渐变的版本。

## 色彩与字重
颜色仅 `#000000`、`#FFFFFF`、`#2563FF`，中性灰作为边框/次级文字/禁用层。原生 NSAppearance 遵循系统浅色/深色，图标色需各模式可读；黑白蓝的品牌是约束，不等于每个像素只能三种 RGB 值。建议 SF Pro + 苹方；标题 18–20pt semibold，功能名 13pt medium，说明 11–12pt regular，快捷键用 SF Mono 的适当字重。文字对比度、VoiceOver、键盘焦点必须可用。

## 主窗口：窗口宽度 540–590pt，随系统动态字体自适应
- 使用真正的 NSWindow 标题栏与系统关闭按钮，不绘制网页“红黄绿”假按钮。
- 顶部：MORIQ 标识与产品名，下面“功能设置”和一句简短副标题，**不要再加菜单、统计、卡片、推荐**。
- 主体：5 行，建议每行 72–80pt，高度随字号增长。分隔线 1px 中性灰。
- 左侧 36pt 单色或蓝色线性图标，居中对齐；接功能名和一行操作说明，右侧是“演示”次级按钮和原生 Toggle。
- 功能顺序固定：转换圆盘、AI 助手、文件暂存架、剪贴板、超级截图。
- “演示”按钮需要支持 disabled 状态但**关掉功能仍应允许演示**，以便用户知道关闭的是什么；演示无系统副作用。
- 点击开关即更新持久配置；异步启动失败则恢复先前状态并弹出可理解的错误，而不是开关看似打开但功能失效。

## 演示弹窗
- 点击每个功能行“演示”才弹出 NSWindow/NSPanel；**主窗口永远没有固定演示区**。
- 弹窗标题栏显示功能名，右上角小关闭按钮；正文大面积 16:9 或近似宽屏的 Mac 桌面动画。
- 画面右上角、内部留边 12–16pt，蓝色“↻ 重新播放”，**唯一的播放控制**。没有底部文字、步骤标签栏、步骤按钮、进度条。
- 场景内可以用真实模拟的 Finder、鼠标指针、文件图标帮助理解；整体风格与真正工具一致。播放结束停最终画面，直到关闭或重新播放。
- 演示仅驱动本地状态机，不读取用户桌面、不调用真实转换/AI、也不触发系统权限弹窗。

## 系统浮层视觉
**轮盘**：直径约 210–280pt，中央当前格式图标，外环每块 40–75pt 可选区域，黑底、蓝色当前高亮，选区之间明确间隔；跟随鼠标附近但始终收敛于可视屏幕范围。对不适用选项不显示。

**AI 胶囊**：底部中央浮起，默认宽 120–170pt、高 38–46pt；激活后平滑拓展到宽 360–480pt、高度随内容限制，黑底白字，蓝色状态圈和细微发光；多轮聊天可在有限高度滚动。不可盖住 macOS Dock 的点击区域；支持系统字体放大。

**暂存架**：侧边 8–14pt 提示条 + 展开后 130–260pt 面板；卡片堆叠但不要模拟复杂 3D；随拖拽位置选择对应显示器。

**剪贴板**：定位在当前焦点屏幕/鼠标附近的紧凑浮动搜索框，建议 350–460pt；上下键快速选择，Enter 复制，二次动作粘贴；保留来源 App 与类型而不堆图标。

**超级截图**：框选过程中屏幕变暗，选区透亮，尺寸角标可选；截图完成后在选区边缘出现深色 6 项工具条：复制、OCR、翻译、标注、贴图、问 AI。翻译结果在选区附近悬浮，内容过多可滚动，不挤出显示器。贴图窗口自身带最小关闭入口。

## 状态一致性
每个 UI 设计正常/悬停/按下/聚焦/禁用/加载/失败/成功/系统减少动态效果共九种状态。主功能开关在不同页面或重启后保持一致。权限问题与功能未启用分开显示。禁止只有“蓝色亮一下”却不告诉用户任务失败。
