# MORIQ 动效详细分镜、运动参数与品牌开场

## 目标体验
“操作跟随手势、快速且可靠”。所有动效都服务理解：出现说明工具已就绪；磁吸说明即将选择；短促完成反馈说明操作成功；消失说明任务结束。避免莫名其妙拆分 Logo 与闪白转场。

## 时间建议（是设计起点，需真机调优）
- 悬浮窗入场 180–260ms，缩放 .92 → 1、透明 0 → 1、位移 8 → 0pt。
- 圆盘弹簧 240–360ms，初始缩放 .7 → 1、旋转 -12° → 0°，临界阻尼（不反复弹跳）。
- 圆盘选区高亮 80–120ms。磁吸位置 < 12pt，不能移动实际释放目标导致误操作。
- AI 胶囊出现 180–220ms，展开 300–420ms；内部内容延迟 100ms 淡入。
- 暂存架弹出 220–320ms，离开且无拖拽后延迟 600–900ms 再收起。
- 截图工具条出现 130–190ms；翻译结果显示前有明确加载态但不得伪造结果。
- 系统 Reduce Motion 开启时移除旋转和大位移，只淡入/淡出 100–150ms。

## 五个“演示”动画分镜（演示窗口全自动，可重复）
1. 转换圆盘（约 5s）：Finder 展示 `.heic` → 鼠标抓起文件 → Shift 键轻触提示（在桌面场景内）→ 圆盘从鼠标附近弹开 → 指向 PNG，扇区变蓝 → 松手 → 新 `.png` 出现在原文件旁边 → 停最终帧。重播按钮始终在桌面右上。
2. AI（约 5s）：IDE 窗口显示两行报错 → `⌘ ⇧ Space` 快捷键视觉提示 → 底部黑胶囊冒出 → 展开 → 显示用户点击“附加屏幕选区”，预览要发送的范围 → 显示一段示例流式回复 → 停最终帧；用户可点 Esc 退出演示弹窗。
3. 文件暂存（约 4s）：Finder 2 个文件 → 指针向右边缘拖 → 边缘高亮 → 暂存架滑出 → 2 个文件沉入叠卡 → 指针离开后贴边收起，保留数字 2 → 停帧。
4. 剪贴板（约 4s）：文本被复制 → 另一个项目被复制 → 按 `⌘ ⇧ V` → 紧凑搜索框出现 → 输入关键词 → 第一条高亮 → 确认粘贴 → 还原原应用焦点。
5. 超级截图含翻译（约 5s）：浏览器英文段落 → `⌘ ⇧ X` → 框选 → 右侧出现 6 项工具条 → “翻译”高亮 → 结果卡英文原文变为中文译文可切换 → 复制译文 → 停最终帧。

## 品牌动画：一生二、聚合、字标显现
客户认可逻辑：一个标记引出两个，旋转归于一个完整的圆形品牌标识，之后 MORIQ 字标出现。视觉因果是从“单点工具”到“协作工具”再到“统一效率核心”。

**建议最终原生实现**（首选 SwiftUI/Core Animation）：
- 0–0.45s：单个 MORIQ 图形在画面中心出现（轻微缩放，不扭曲内部形状）。
- 0.45–1.35s：它产生一个缩小的虚影/第二个完整同形标记，两者沿左右方向平滑分开，沿统一中心缓慢公转。
- 1.35–2.15s：两者围绕同一中心旋转后重叠收敛为一个完整标记；不要把标志内部曲线随机液化成全新形状。
- 2.15–3.0s：最终标记移到左侧，**MORIQ** 字标从右侧 12pt 缓动入场并从透明转实。
- 3.0–3.6s：完整 Lockup 稳定展示，无闪光、无粒子炸开、无多余文案。
- 品牌动画用于首次介绍、关于界面或宣传，**不应该每次打开设置窗口都强制播放**。

交付动画：`06_BRAND/Animation/MORIQ_Brand_Reveal_30fps.mp4`、`MORIQ_Brand_Reveal.gif`、`Previous_Approved_Concept.gif`。MP4 是由已认可的位图图形渲染生成，30fps；后续拿到 SVG 母版后应改为更平滑的矢量 CAKeyframeAnimation / SwiftUI 动画。

## 技术实现重点
示例不要一组定时器相互依赖导致“重新播放”错乱。各动画采用显式 enum 状态机 `idle/triggering/appearing/selecting/completing/done`，重播时 cancel 旧任务、清理状态、重新开始；关闭窗口 cancel 所有 Task。动画与真实转换服务完全隔离，不请求访问用户屏幕。
