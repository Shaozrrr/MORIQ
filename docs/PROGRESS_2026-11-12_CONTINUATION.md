# MORIQ 继续开发记录 · 2026-11-12

以下只记录本轮已有证据的变化；早期 `KNOWN_GAPS.md` 部分状态已过时。

## 发行准备更新

- Apple 开发者证书仅在 Zhaoru Shao 团队创建了 Developer ID Application，本机钥匙串显示有效签名身份；没有操作其他团队。
- 匿名重建的媒体引擎已合入项目并安装到本机 Debug 应用，应用重启和功能开关状态检查通过。关键图像、动画、音频、视频以及 Rosetta 样本已测试；完整发行验收见 `FFMPEG_ANONYMOUS_CANDIDATE_ACCEPTANCE_2026-11-12.md`。
- 当前安装版依赖检查提示主程序只有 arm64：它是本机 Debug 测试版，不能视为 Intel 可用的公开发行包。双架构 Release、最终签名和公证需对发行候选单独检查。
- 最新源码的双架构 Release 已完成 Developer ID 签名及已知依赖检查，Apple 公证已提交，结果尚待确认。不得将提交本身视为通过。
- 截图和字幕之外，HTML 固定尺寸元素的居中 cover 背景已实际经 Word 验证，并修复随包办公引擎缺少系统中文字体导致的回转 PDF 中文不可见；更复杂 CSS 与其他机器仍须验收。更新已安装至本机 Debug 应用并确认可启动。
- 字幕隔离整链路通过 50 秒合成声音的系统采集、识别与翻译；真实会议、长期运行、已签名发行版及其他机器尚未验证。

## 已实现并更新到本机应用

- 完成过首次引导的用户，在本次启动的全部权限检查通过后自动进入功能页；未通过时仍留在权限页。用户手动打开权限设置时不会自动离开。已在本机安装版完成一次正常进入后退出、重启并自动进入的实际检查；未覆盖全新用户、拒绝或撤销权限的完整流程。
- 修复截图在同一语言连续翻译时第二次可能不触发的问题。`Tests/ScreenshotRepeatedTranslation/run.sh` 使用合成图片和独立剪贴板，实际完成两次本机 OCR 与翻译，第二次前添加了标注。
- HTML 转 Word 补充受限的两行两列表格图片背景：固定宽高、短且不重复文本和本地图。真实 Word 检查了中文文字和背景位置，并保留原生文字。复杂 CSS、跨页、合并/嵌套单元格和编辑后背景重新布局仍未覆盖，保真提示保留。详见 `HTML_BACKGROUND_ELEMENT_COVER_2026-11-12.md`。

## 本地原型，尚未上线

- 统一 AI 网关在原有回环联调基础上增加 SQLite 会话及持久请求额度，覆盖并发、过期撤销、跨进程竞争和数据库失败测试；客户端增加显式配置才启用的路由，未配置时沿用现有连接。已用本机模拟服务验收文本、22 张合成图片、流式响应、认证失败、取消与重定向拒绝。未接入正式身份签发或真实部署。额度按请求数计，不是实际费用账单。详见 `Services/ManagedAI/README.md`。
- 剪贴板新增使用 MORIQ 实际 Debug 进程的跨进程隔离验收：合成富文本及图片经收藏、重启恢复后，由另一原生进程检查文字、下划线及像素。使用独立剪贴板和测试钥匙串；不代表通用剪贴板及第三方应用已验收。
- 超级截图隔离预览中，实际点击复制并由另一进程验证合成 PNG 尺寸与中心像素；未验证实际画框后的像素。CUA 对测试窗口的拖动返回 `noWindowsAvailable`，因此本轮未能完成系统截图快捷键与 Shift 拖动互斥的真实跨应用验收。
