# 本机字幕识别模型对照（2026-11-13）

在同一台 Apple M6、32 GiB、macOS 27.0 上，使用 MORIQ 当前 `moriq-speech` 滚动窗口引擎（CPU、4 线程、相同参数）和 LibriSpeech dummy 前 8 条公开真人朗读，比较已随包多语言 Whisper base（141 MiB）与 [whisper.cpp 官方模型仓库](https://huggingface.co/ggerganov/whisper.cpp)多语言 small（465 MiB）。small 下载文件 SHA-256 与仓库 LFS 标识 `1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b` 一致。没有录音、采集用户音频或调用付费服务。

前后各 4 条独立拼接，分别计算词错误率 WER（替换、插入、删除）；噪声为固定种子、RMS 0.01 白噪声，并不代表统一信噪比。单次测得：

| 片段 | 音频 | 模型 | WER | 处理耗时 |
| --- | --- | --- | --- | --- |
| 0–3，33.05 秒 / 83 词 | 干净 | base | 9/83 = 10.8% | 4.38 秒 |
| 0–3 | 干净 | small | 11/83 = 13.3% | 10.09 秒 |
| 0–3 | 噪声 | base | 17/83 = 20.5% | 3.33 秒 |
| 0–3 | 噪声 | small | 13/83 = 15.7% | 10.22 秒 |
| 4–7，53.29 秒 / 117 词 | 干净 | base | 25/117 = 21.4% | 5.11 秒 |
| 4–7 | 干净 | small | 24/117 = 20.5% | 16.17 秒 |
| 4–7 | 噪声 | base | 24/117 = 20.5% | 5.25 秒 |
| 4–7 | 噪声 | small | 28/117 = 23.9% | 16.84 秒 |

八条样本仅一位朗读者，合计 200 词，small 在这组样本上并未稳定优于 base，而处理耗时约 2–3 倍；因此不能凭模型大小直接更换默认，也不能据此断言两个模型的总体优劣。该测试通过管道尽快送入音频，并非实时采集：耗时不包含等待音频、UI、翻译或显示的延迟，也没有覆盖真实会议、口音、专业术语、音乐、设备切换及中文。WER 包含当前引擎硬分段、接缝重复影响。后续须以更多说话人、真实授权音频、翻译质量和端到端延迟验收，并与在线方案同样输入公平比较。

可复现：先按 `Tests/LiveCaptionsRealSpeech/README.md` 准备公开测试音频和参考文本，下载官方模型并校验摘要，再运行 `python3 Tests/LiveCaptionsRealSpeech/compare_models.py --start 0 --count 4 Vendor/SpeechEngine/ggml-base.bin /path/to/ggml-small.bin`，另用 `--start 4 --count 4` 运行第二组。脚本不下载模型、不采麦克风、不输出样本文本。
