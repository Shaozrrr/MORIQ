## 可重复生成

在 MORIQ 项目根目录，使用当前候选应用包的绝对路径：

```sh
sh Tests/CapabilityInventory/run.sh /absolute/path/MORIQ.app > /tmp/moriq-capabilities.json
python3 Tests/CapabilityInventory/test_inventory.py /absolute/path/MORIQ.app
```

脚本将七个转换源码复制进临时目录编译，临时应用只读引用所提供应用包的 Resources；自动清理临时目录，不访问网络或用户文档。输出包含逐对条件、环境探测和静态图片系统编解码能力。应用包必须存在且包含 Resources。注意源码取自当前工作区，引擎资源取自所提供的应用包；脚本不能证明该包的二进制由该源码构建，也不执行实际转换。归档为多文件操作而非普通格式对，单列环境条件，不计入下列逐对行数。
