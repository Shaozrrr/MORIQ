# 11｜风险与待确认事项

## 1. OpenAI 商业授权（最高优先级）

**状态：未解决，必须在收费发布前解决。**

- SIWC plan usage 自助路径目前面向开源项目/本地个人项目/选定私有应用。
- 付费或远程托管应用需要先申请相关资格。
- SIWC Terms 要求用户不付费、不升级应用也能使用 ChatGPT plan 连接能力。
- “基础问答免费、持续监控 Pro 收费”是否符合具体条款，需要 OpenAI 对产品形态书面确认。
- 如果未确认：先发布免费开源本地原型；或者商业闭源版改为 BYOK API Key 模式。

## 2. 用户账户资格

- 不是所有 ChatGPT 账户、计划、地区、工作区都保证可用。
- 账户/工作区管理员策略可能影响 OAuth 授权。
- ChatGPT plan usage 有用量限制，不等于无限 API。
- `model/list` 只是模型目录，不是 entitlement 检查；必须实际完成一次推理请求。

## 3. Codex App Server 发行

- App Server 是官方提供的集成接口，但 Codex CLI 的安装、版本、分发许可和兼容性需要验证。
- 初期可要求用户安装官方 Codex CLI；之后评估是否能合法打包 App Server。
- App Server 协议会演进；应固定测试版本、在 CI 里生成/核对 schema，并为协议变化留兼容层。

## 4. macOS 捕获限制

- 用户必须授予屏幕录制权限。
- 某些 DRM、受保护内容、密码输入或安全窗口可能无法捕获。
- 不同 macOS 版本、多显示器、Space、Stage Manager、Dock、窗口隐藏等需要实测。
- Accessibility 树不保证每个 App 都暴露完整内容。
- OCR 也可能错读、漏读；应把来源和时间戳带入上下文。

## 5. Live 感知性能

- SCStream 长时间运行会消耗 CPU、内存、电量。
- 视频/动画/滚动页面会产生大量帧；必须本地抽样、差异检测、限频。
- 不能默认“每秒所有帧都上传模型”。
- 首版只做本地关键帧缓存，用户提问时才挑选少量上下文。

## 6. UI 风险

- NSPanel 焦点行为容易影响用户原 App；必须在多应用真实测试。
- Dock 自动隐藏、不同显示器、刘海屏、全屏 Space 会影响底部定位。
- 长答案和连续追问必须有滚动/高度上限，避免用户反馈的“截断很难受”。
- Siri 风格光效是原创实现，不使用 Apple 私有资源；动画需控制 GPU/能耗。

## 7. 需要用户后续确认的事项

1. 最低 macOS 版本最终定为多少（建议先以 14.0 做开发基线）。
2. 首发是否要求用户预先安装 Codex CLI，还是愿意等候打包/许可验证。
3. SIWC 商业收费边界取得 OpenAI 书面确认后，是否采用开源 + Pro 模式。
4. 若 SIWC 商业授权不通过，是否接受商业版只做 BYOK API Key。
5. Pro 最终价格与买断/订阅方式（暂不锁定）。
6. Live 模式是否作为首发 Pro，还是先作为免费测试功能。
