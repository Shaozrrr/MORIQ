# 03｜UI / UX 交接规格

## 1. 总体设计原则

ScreenBuddy 不是一个缩小版 ChatGPT，也不是一个常驻桌面 Widget。它应像系统级快捷能力：平时完全不存在，用户需要时从屏幕底部出现，回答完成后随时消失。

**浮窗只有一个对话框。所有设置在顶栏。**

## 2. 主对话框

### 2.1 默认状态

- 完全隐藏；桌面上不显示胶囊、悬浮按钮或常驻提示。
- 唯一唤出方式为全局快捷键（默认 `⌥ Space`）。
- 菜单栏图标不是主聊天入口的替代品，只负责设置和状态。

### 2.2 唤出后的输入态

参考用户反复确认的小尺寸原型：
- 默认宽度目标：约 290 pt（允许 280–340 pt 自适应）。
- 高度目标：约 44–48 pt。
- 圆角：胶囊式连续圆角，半径约 22–26 pt。
- 位置：当前显示器底部中央，基于 `NSScreen.visibleFrame` 计算，默认距可用区域底部 16–22 pt。
- 内部只有 placeholder “问问当前屏幕…”、输入文字和一个简洁发送箭头。
- 不显示 Logo、ScreenBuddy 字样、标题、当前应用名、刷新按钮、截图按钮、工具栏、设置齿轮或状态栏。
- 对话框背景为轻量半透明材质；边缘有细腻彩色流光。

### 2.3 思考态

- 对话框尺寸基本不变。
- 边缘 Siri 风格光带流速略微加快，亮度提高但不能刺眼。
- 输入框下方可以出现一行很小的“正在理解…”状态；如空间不够可用光效表示，不增加独立大面板。
- 必须支持取消请求。

### 2.4 回答态

- 同一个圆角对话框向上展开，不另弹一个窗口。
- 宽度建议 340–420 pt；不要在用户未请求时撑满屏幕。
- 高度根据内容增长，最大不超过屏幕可用高度的 55–65%。
- 答案区内部滚动；输入行固定在底部或顶部（建议底部固定，便于继续追问）。
- 不允许出现内容被父容器裁切、按钮压住正文或滚动区域无法滚到底的问题。
- 支持 Markdown 基础排版、列表、代码、表格和链接；首版优先保证纯文本和列表稳定。
- 长答案超出上限时内部滚动，不能缩小字体硬塞。
- 回答完成后边缘光效降低速度和亮度，保持柔和的静态呼吸效果；用户继续输入时再进入活动状态。

### 2.5 关闭和焦点

- Esc：关闭浮窗并把键盘焦点交还给原前台应用。
- 再按快捷键：重新打开并聚焦输入框。
- 点击浮窗外：默认不立即关闭，避免误触丢失输入；可在设置中选择点击外部关闭（后续）。
- 浮窗显示前必须记录原前台应用；不能在弹出后把 ScreenBuddy 自己识别成目标窗口。
- 用户在输入框里按 Enter 发送；Shift+Enter 换行。

## 3. Siri 风格边缘光效

用户希望类似 iPhone Siri 的彩色流动跑马灯。实现要求：

- 用 SwiftUI `AngularGradient` / `Canvas` / Core Animation 自绘圆角边缘光带。
- 光带沿圆角矩形边缘连续流动，不能只是整条矩形描边换色。
- 颜色范围可以是 Siri 风格的蓝、青、紫、粉、橙过渡；这是交互动效，不改变品牌 Logo 只用黑色与钴蓝的规范。
- 唤出：从低透明度渐显，约 180–260ms。
- 思考：光带运动加快，约 1.2–1.8 秒一圈，具体需真机调试。
- 回答：减慢到约 4–6 秒一圈，亮度降低。
- 隐藏：光带随面板一起淡出，不残留独立光效。
- 不使用 Apple 私有 Siri 资源或声称“完全复刻 Apple Siri 组件”；做原创的 Siri-inspired 视觉动效。
- 支持 Reduce Motion：关闭持续旋转，改为静态渐变边缘。

## 4. 顶栏菜单（所有设置的唯一入口）

点击 macOS 顶部菜单栏图标后显示紧凑 Popover，建议分组：

1. **AI 连接**
   - 未连接：`连接 ChatGPT`。
   - 已连接：显示账户/连接状态、授权是否包含 plan usage、`重新连接`、`断开连接`。
   - 显示“使用你的 ChatGPT 套餐；额度和模型可用性以账户为准”。
2. **屏幕权限**
   - 屏幕录制权限：已授权 / 未授权 / 需要重启或重新打开应用。
   - Accessibility（若后续启用）：可选增强能力，不是截图主流程的必需权限。
3. **快捷键**
   - 显示当前快捷键。
   - 修改、冲突提示、恢复默认。
4. **屏幕感知**
   - 主动截图（默认）。
   - 持续感知开关、当前捕获目标、暂停/停止、清空当前缓存。
5. **隐私控制**
   - 排除应用列表。
   - 发送前预览（可选）。
   - 清空本地上下文/历史。
6. **历史与帮助**
   - 打开本地历史（可以是 Popover 内子页，不另建复杂设置窗）。
   - 打开教程、反馈、关于、退出。

顶栏 Popover 可以有分组和子页，但不应该变成一个复杂的独立设置应用。

## 5. 顶栏图标

- 用用户选定 Logo 的单色简化版本。
- 无正方形底框、无文字。
- 浅色顶栏使用黑色模板图；深色顶栏使用白色模板图。
- 推荐 AppKit `NSStatusItem.button.image` + template image，避免使用已废弃的 `NSStatusItem.image` 属性。
- 图标宽高约 18–20 pt；需要在真实 macOS 顶栏测试，不依赖品牌板上放大的展示效果。

## 6. UI 状态机

`Hidden → Appearing → Input → Capturing → Thinking → Answering → Input`。

异常分支：
- 未连接 AI：浮窗提示连接入口（不在浮窗放复杂设置），同时顶栏 Popover 显示连接操作。
- 无屏幕权限：显示短提示“需要屏幕录制权限”，提供打开系统设置入口。
- 捕获失败：说明窗口不可捕获/需要重新选择，不允许静默换成其他窗口。
- AI 额度耗尽：显示账户额度/使用限制提示，提供打开 ChatGPT Usage 的链接。
- 网络失败：保留用户问题，允许重试。
- 用户取消：停止请求并保留已完成文本。

## 7. 视觉规范

- 品牌白底、黑色 `#000000`、钴蓝 `#2563FF`。
- 对话框可使用系统材质；不要使用大面积纯黑背景。
- 不使用过度阴影、夸张发光或厚重描边。
- 字体优先 SF Pro / 系统字体。
- 视觉目标：安静、精致、轻量、macOS 原生，不像第三方聊天工具。

## 8. UI 验收

- 隐藏时不占桌面空间。
- 展开时只有一个圆角对话框。
- 对话框出现在底部中央，且避开 Dock。
- 输入态、思考态、回答态过渡自然。
- 长回答滚动到底部后最后一行完整可见。
- 顶栏 Popover 包含全部设置；浮窗不出现设置按钮。
- 深浅色模式下菜单栏图标对比度正确。
