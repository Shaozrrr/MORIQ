# 01｜已确认的产品决策

本文件是项目的“不可擅自改动清单”。如其他文档或 Codex 的默认偏好与本文件冲突，以本文件为准。

## 1. 产品定位

- 名称：**ScreenBuddy**。
- 平台：macOS 原生应用，第一版不做 Windows / Web / iOS。
- 产品形态：菜单栏常驻的轻量桌面助手。
- 核心能力：理解用户当前屏幕内容，支持主动提问、连续追问，以及用户主动开启的持续屏幕感知。
- 目标用户：普通 Mac 用户，不限定开发者；网页、文档、表格、软件界面都属于目标场景。

## 2. 主交互

- 平时完全隐藏，不常驻显示一个胶囊或悬浮图标。
- 只能通过全局快捷键唤出主对话框；菜单栏图标只负责设置、连接状态和控制。
- 默认快捷键建议 `⌥ Space`，但必须支持自定义和冲突检测。
- 对话框出现在当前使用显示器的底部中央，使用屏幕可用区域定位，避开 Dock。
- 对话框是一个圆角玻璃质感气泡，不是黑色大面板。
- 对话框内部只放输入框和回答内容；不放 Logo、产品名、标题栏、工具按钮行或状态栏。
- Siri 风格的彩色流动边缘光效用于唤出、思考、回答状态。它是自绘的原创动效，不调用 Apple 私有组件，也不复制 Apple 的资源文件。
- 回答时同一个对话框向上扩展；长回答在内部滚动，不能截断，输入区保持可用。
- Esc 收起；再次按快捷键重新唤出。关闭不能导致后台捕获任务继续运行。

## 3. 设置入口

用户明确要求：**设置全部放在 macOS 顶部菜单栏。**

- 菜单栏图标点击后打开一个紧凑 Popover / 菜单。
- 不做独立 Preferences 大窗口作为主要设置入口。
- 所有设置从顶栏入口可达：AI 连接、权限、快捷键、截图模式、持续感知、排除应用、隐私、历史、关于、退出。
- 顶栏图标本身不带文字、不带正方形底框；浅色菜单栏使用黑色模板图，深色菜单栏使用白色模板图。

## 4. 屏幕感知

- 两种模式都保留：主动截图为默认；持续感知由用户主动开启。
- 主动模式：用户提问时获取当前窗口/显示器/用户框选区域的快照。
- 持续模式：用户明确选择目标窗口或显示器后开启本地采集；本地做变化检测、OCR 和短期上下文缓存。
- 不把每一帧持续上传给云端模型。
- 默认只有用户提问时才向 AI 发送所需的截图/文字；任何后台自动 AI 请求都必须单独取得明确授权。

## 5. AI 连接与费用

- 用户不希望 ScreenBuddy 替用户支付 Token，不建设自有 Token 中转站。
- 目前优先路线：官方 Sign in with ChatGPT（SIWC）授权用户自己的 ChatGPT plan usage，再通过本机 Codex App Server 处理文字和截图。
- 不能读取用户 Codex 私有 cookie、session 文件或本地认证缓存；不能模拟私有接口。
- 不能把 Codex 订阅描述成无限用量；用户受自己套餐、地区、工作区策略、模型可用性和使用限额约束。
- BYOK（用户自己的 API Key）可作为商业化备选/后续 Provider，但第一条技术主线先验证 SIWC + Codex App Server。
- 付费功能设想：持续感知、最近变化记忆、多窗口上下文、高级本地历史等。收费边界必须先通过 OpenAI 政策确认，见 `08_BUSINESS_AND_POLICY.md`。

## 6. 品牌视觉

用户最终选定附件 `assets/brand_board_user_selected.png` 这一套：

- 白色背景。
- 两个品牌色：纯黑 `#000000` 和钴蓝 `#2563FF`。
- 主符号：黑色倾斜屏幕/面板，搭配右下方错位的蓝色面板。
- 字标：黑色粗体无衬线 `ScreenBuddy`。
- 不得重新设计成 S 丝带、蝴蝶结、Copilot 类交叠环、星星、聊天气泡、叶片、轨道或普通窗口角标。
- 顶栏图标使用该符号的单色版本，无外框；浅色模式黑色、深色模式白色。
- 交接包中的 PNG 是用户选定的参考素材和裁切预览，不是正式矢量母版。正式发布前需人工/矢量工具描摹成 SVG/PDF/Asset Catalog，保持原轮廓。

## 7. V1 不做

- 不做 MCP Server。
- 不做 Codex 反向调用 ScreenBuddy 的工具集。
- 不做电脑自动点击、自动输入、自动执行 Shell。
- 不做语音输入/语音播报。
- 不做团队协作、云端同步、账号系统、远程托管。
- 不做 ScreenBuddy Cloud / Token 充值 / 模型代理。
- 不做复杂 Action 商店或插件市场。
- 不在浮窗里放任何设置入口。
