# 10｜验收测试清单

## A. 菜单栏与快捷键

- [ ] App 启动后只显示菜单栏图标，不出现 Dock 主窗口。
- [ ] 浅色菜单栏显示黑色单色图标。
- [ ] 深色菜单栏显示白色单色图标。
- [ ] 顶栏图标无方框、无文字。
- [ ] 点击顶栏图标打开设置 Popover。
- [ ] 所有设置都能从顶栏找到。
- [ ] ⌥ Space 可在其他 App 前台时唤出。
- [ ] 快捷键冲突能提示。
- [ ] 退出 App 后全局快捷键注销。

## B. 主浮窗

- [ ] 默认完全隐藏。
- [ ] 唤出后位于当前显示器底部中央。
- [ ] 使用可用屏幕区域定位，避开 Dock。
- [ ] 浮窗只有一个圆角对话框，无 Logo/标题/工具栏/设置按钮。
- [ ] 输入框自动获得焦点。
- [ ] Enter 发送，Shift+Enter 换行，Esc 收起。
- [ ] 回答态在同一个对话框中向上扩展。
- [ ] 长回答可滚动到最后一行，不截断。
- [ ] 连续追问沿用正确 thread。
- [ ] 关闭后焦点回到原应用。

## C. 截图

- [ ] 首次捕获前正确申请权限。
- [ ] 快捷键触发时记录原前台 App。
- [ ] 不捕获 ScreenBuddy 自身。
- [ ] Safari / Chrome / Finder / TextEdit / Numbers / Excel 等场景可测。
- [ ] 多窗口时选择正确窗口。
- [ ] 窗口关闭/隐藏/最小化时给出明确提示。
- [ ] DRM/安全窗口不能捕获时不伪装成功。
- [ ] Retina、多显示器、不同缩放比例坐标正确。
- [ ] 区域框选的裁切范围正确。

## D. SIWC / Codex

- [ ] 首次授权打开官方 ChatGPT 浏览器授权。
- [ ] 用户可以取消授权。
- [ ] 仅身份登录但未授权 plan usage 时不启用 AI 请求。
- [ ] Token 本地保存，日志中无 Token。
- [ ] Codex App Server 启动失败时给出安装/诊断提示。
- [ ] initialize / initialized 顺序正确。
- [ ] thread/start、turn/start 成功。
- [ ] localImage 图片输入成功。
- [ ] item/agentMessage/delta 流式显示。
- [ ] turn/completed 只在 completed 状态下判成功。
- [ ] Token refresh 后可 resume thread。
- [ ] 额度耗尽/模型不可用/网络失败/登录过期可区分。
- [ ] 不读取 Codex 私有 cookie 或 session 缓存。

## E. Live 持续感知

- [ ] 默认关闭。
- [ ] 开启前明确告知捕获目标和本地缓存方式。
- [ ] 使用系统 picker 选择目标。
- [ ] 顶栏可看到 Live 状态和目标。
- [ ] Pause 立即暂停。
- [ ] Stop 释放 stream 并清理缓存。
- [ ] 重复帧不会无限进入缓存。
- [ ] 滚动/动画页面不会造成无限高频缓存。
- [ ] 默认不会后台自动调用模型。
- [ ] 退出 App、权限撤销、锁屏、睡眠等状态能正确处理。

## F. 隐私

- [ ] 截图默认临时保存并按策略删除。
- [ ] 历史默认不保存原始截图。
- [ ] 排除应用列表生效。
- [ ] 清空上下文确实删除缓存。
- [ ] Key/Token 不写日志、不上传自有服务器。
- [ ] Live 开启需要明确用户操作。
- [ ] 自动化/后台模型调用如未来加入，必须单独征得用户同意。

## G. 品牌

- [ ] 使用用户选定的黑色面板 + 钴蓝错位面板 Logo。
- [ ] 品牌色仅黑 `#000000` 和蓝 `#2563FF`；白色作为背景。
- [ ] 主字标准确为 ScreenBuddy。
- [ ] 顶栏单色版是同一图形，不带框。
- [ ] 18×18 pt 下清晰可辨。
- [ ] 未擅自使用已废弃的其他 Logo 方向。
