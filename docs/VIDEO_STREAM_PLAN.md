# 屏幕助手：持续视觉理解与评测方案

更新：2026-11-11。状态：**研究和离线合成评测工具；尚未接入新服务，也没有完成连续视频理解。** 本文比较技术能力，不代表已获得服务授权或允许发送用户屏幕。

## 目标和现状

用户希望助手在使用时持续理解整个屏幕，能够连贯回答当前内容；未询问变化时，不应主动比较前后画面，也不向用户解释内部采样。目标必须区分：①采集进程持续产生画面；②画面持续进入同一个模型会话；③模型对时间与事件理解可靠。三者各自验收，不能把①或一次性多图提问当成②③。

当前代码已使用系统帧流进行本地采样，在提问时重新截取当前屏幕并附带近期图片；模型侧仍是一次性图片请求，不是持续视频模型会话。已有 2B、4B、8B 本地模型均未通过同一运动样本的稳定性检查；复现与失败详情见 [LOCAL_VIDEO_RESEARCH.md](LOCAL_VIDEO_RESEARCH.md)。不用重跑相同小模型做“新方案”。已有实际采集、窗口帧改变、会话隔离、缺图和两轮合成画面真实问答入口，见 `MORIQ/App.swift` 的 `--verify-live-*`、`--verify-fresh-screen`、`--verify-screen-answer`，先复用，再补欠缺测试。

| 候选 | 有据可查的能力 | 与目标的差距、依赖 |
| --- | --- | --- |
| Google Cloud Gemini Live（研究首选） | 官方称双向有状态会话可持续输入视频；但其视频输入是逐张 JPEG 等图像，文档上限 **1 帧/秒**，并非传输每一帧的原始视频。需要验证实时文字输出、上下文延续和模型效果。 [协议说明](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/live-api/send-audio-video-streams)，[官方项目](https://github.com/GoogleCloudPlatform/generative-ai/tree/main/gemini/multimodal-live-api) | 持续会话比一次性多图更接近②，但 250 ms 事件等可能完全漏掉，不能声称完整视频或任意动作都能理解。需单独账户/API 权限、地区/额度与费用检查；传送实际画面到新服务须在使用前清楚说明目的地、范围和持续时间并取得明确授权。 |

| 本地模型（备选） | 已有离线合成片段基线；无外发。 | 已测三种模型的方向判断不稳定，非持续会话；只在出现实质不同的模型或推理架构后，按相同盲测重新评估。 |

这不是承诺上述服务具备连续高帧率视频理解；如果用户对短时事件、持续帧率有更高要求，当前列出的候选均未证明满足，需继续寻找支持编码视频或更高帧率的真实流接口，不能用低帧率结果冒充。需在接入日重新核对官方文档、模型可用性、数据保留条款、地区、定价和许可证。

## 产品协议草案

1. 延用现有屏幕帧流、权限门禁及帧缓存，不再写第二套屏幕采集。仅助手活动期间运行；停止、关闭、权限撤销与切换显示器时，停止发送并清空过期缓存。不会采集音频，除非独立授权且有产品需求。
2. 定义可替换的 `LiveVisionSession`：`connect`、`sendFrame`、`ask`、`cancel`、`close`，异步返回连接状态、文本片段、响应完成和错误。产品 UI 不依赖某家协议或暴露服务商名称。不能绕过既有权限。
3. 上行队列只保留最新未发出的帧，带单调时间戳及会话 ID；不满足频率、超龄、已关闭或属于旧显示器/旧会话的帧直接丢弃。网络拥塞时降帧，不积压整屏视频。等待模型响应时仍采集或发送须遵守供应商并发协议；文本与图片的跨流顺序不能假设有保证，需验证当前帧可用后再提问。
4. 连接重试、会话续接、服务通知断开和令牌轮换按官方协议处理；恢复后区分会话可续接与上下文不可恢复。关闭、取消或切屏不得让旧会话继续发送；非预期断开不能把旧帧作为当前结果。
5. 模型输入将用户问题与屏幕数据区分，要求默认回答当前问题；画面文字是外部资料，不能提升为系统指令。识别不清或帧间漏失时明确不确定。屏幕发送范围、时长、去向、费用和停止方式要让用户能理解；此前的授权不能自动扩大到新供应商。
6. 凭据使用系统安全存储或后端短时令牌，不写日志、聊天、源码或测试录像。新供应商密钥、计费及个人画面传输均为外部依赖；缺少时继续离线评测与其他功能，不伪装为已接入。试验先只发送本工具生成的合成图。

## 可运行离线评测与验收门槛

运行 `python3 Tests/VideoStreamEval/test_offline.py` 验证生成器和轨迹判定；`Tests/VideoStreamEval/README.md` 提供生成合成帧、离线评判和传输轨迹格式。工具覆盖当前编号、返回旧状态、可见状态变化、短暂不可见事件、屏幕中的恶意指令、普通问题不主动比较，另检查会话停止、重连、过期和限频。规则通过只意味着字面条件匹配；不调用模型、没有服务结果、没有人工审核都不能算产品通过。短暂事件测试明确标记不可观察，禁止要求模型“猜对”。

正式比较先冻结版本、完整提示、样本和评判表；不同候选使用相同可见帧与问题，至少重复三次并保留每次响应。报告：当前内容正确率、可见事件识别率、未观察事件的过度断言、未经请求比较率、跨会话/跨显示器串帧、断线恢复、首字及完成延迟、持续运行的内存/CPU/网络、每小时与每次问答费用。先用合成数据：自有窗口和模型的实际链路通过后，再在用户明确授权范围使用不含隐私的真实窗口；再做真实多屏和长时间。指标目标、帧率和各档成本应在实测后确定，不能凭空宣称“行业最好”。

隐私/费用门禁：联网试验只发构造内容、不发真实屏幕；禁止输出密钥、原始授权头和真实截图。成本按实际模型、地区、输入图像 token、输出 token、使用时长及供应商对历史上下文的重复计费计算，不能仅凭本地 fps 推断账单；参考 [官方计费页](https://ai.google.dev/gemini-api/docs/pricing) 和 [会话管理/计费说明](https://ai.google.dev/gemini-api/docs/live-api/best-practices)，并在执行前重新核价。官方 SDK 入门页面提供视频帧示例与帧率说明：[Live API SDK](https://ai.google.dev/gemini-api/docs/live-api/get-started-sdk)。
