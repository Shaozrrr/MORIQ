# 转换轮盘验收记录（2026-11-11）

本记录区分自动化测试、实现方式与未完成的审查；不表示全部格式均经人工验收，也不表示优于任何竞品。参考 OpenShelf 的格式清单和实际实现： https://github.com/Manan-Santoki/OpenShelf 。

PDF 转可编辑 DOCX 在本机开发环境优先使用 pdf2docx；缺少该引擎时使用系统富文本导出，其他富文本目标使用系统导出，但 PDF 布局、图片、图表、表格不能保证重建。扫描件或混合无文字页的 PDF 转 DOCX 时，所有页面以图片形式保留，文字不可编辑；两页合成扫描件经 DOCX→PDF 回转并检查画面通过。扫描件转 RTF、HTML、ODT 暂拒绝以避免静默丢页；纯文字导出优先使用文字层，对扫描页在本机进行 OCR；扫描文字合成样本通过，不能保证识别准确。正式发布还需处理 LibreOffice 与 FFmpeg 的可用性、分发和许可。

PDF→DOCX 的本机开发质量引擎使用 pdf2docx 和 PyMuPDF：合成粗体、颜色、文字混图片、表格结构通过测试；字体替代和复杂排版仍需审查。PyMuPDF 采用 AGPL-3.0／商业双许可，当前引擎未纳入正式发布包。

Markdown 和 EPUB 使用本机可用的 Pandoc；57 对仅验证合成文本，DOCX→EPUB→DOCX 的合成嵌入图片和缺失资源报错另行通过。沙盒不会读取外部引用资源，遇到无法读取的资源会报错；复杂样式和实际文件仍需审查。Pandoc 仅在开发环境或用户本机安装可用时显示相应格式；其 GPL 许可及正式版引擎分发仍需处理。

多工作表 XLS、XLSX、ODS 转 CSV／TSV 会将每个工作表导出为独立文件，并放入新文件夹。六种组合使用合成双工作表检查内容、分隔符、重名保护及原文件保留；单工作表 21 组回归通过。CSV／TSV 不保留表格样式或公式本身，复杂工作簿仍需审查。

额外内容保真检查：TXT→Markdown／EPUB 后读回，合成代码中的尖括号、星号及类似链接的字面字符保留；多工作表样本另检查中文、逗号、引号、单元格内换行、制表符和公式计算值。

多音轨与文字字幕：合成双音轨＋SRT 字幕输入转 MP4、MOV、M4V、MKV、WebM，均验证第二条音轨可解码、字幕文字可读回；42 对基础视频回归通过。图片字幕、字幕样式和其他容器尚未验收；不兼容的轨道可能导致转换失败。

多视频轨：合成红、蓝双画面转 MP4、MOV、M4V、MKV、WebM，分别解码并检查两路画面颜色；音轨／字幕及 42 对基础视频转换回归通过。不同编码的附加视频轨和封面图仍需验收。

旋转 PDF 页面导出：合成 90 度旋转双颜色页面转 PNG 后检查输出尺寸与左右两个画面区域；多页导出及原文件保护回归通过。

PDF 页面图片导出补充：PNG／JPEG 对四页 0°、90°、180°、270° 的合成内容分别检查尺寸及四个角的方向；裁切框样本检查可见范围、排除裁切框外内容。

无 LibreOffice 的开发测试：PDF→DOCX、RTF、HTML 由系统导出，文字样本可读回；ODT 仍依赖 LibreOffice。系统回退不保证复杂布局和图片完整。

音频精度：合成 24 位、32 位 PCM 样本转 WAV／AIFF／CAF／FLAC，FFmpeg 路径逐样本无损读回；系统路径前三种格式逐样本通过，32 位→FLAC 会提示不可无损转换。48 kHz 立体声样本在八种输出中检查左右声道不同、采样率及时长。32 位 FLAC 在本机系统解码器可读取，其他播放器兼容性尚未验收；长录音仍需检查。

浮点 PCM：包含超出 ±1 的 32 位／64 位浮点合成信号，在 FFmpeg 和系统两条路径下转 WAV／AIFF／CAF 后逐样本比对通过。浮点输入转 FLAC 时提示精度限制，避免静默截断；其他浮点容器兼容性尚需验收。

多项目压缩补充：三种格式验证隐藏文件及文件夹内相对符号链接；选中父文件夹及子文件时，输出移到选中目录之外，避免压缩包把自身收入。大文件、绝对符号链接和真实 Finder 拖放仍未验收。

HTML 图片：DOCX、ODT、RTF、EPUB 中的合成嵌入图片导出为自包含 HTML，并再次转换成 DOCX 后检查图片资源；57 对文字基础矩阵回归通过。输出中无法读取的图片资源会报告错误；复杂图片及视觉排版仍需验收。

Markdown 图片：DOCX、ODT、RTF、EPUB 的带图样本会输出含 Markdown 和资源的文件夹；再转 DOCX／EPUB／HTML 的合成往返通过，缺失图片和输出重名保护通过。只预读 Markdown 所在目录内的本地图片；复杂语法、外部目录图片及视觉版式仍需验收。

Markdown 语法补充：引用式图片（含简写）、内嵌 HTML 图片、含空格与中文的路径可读入；代码块／行内代码中的示例不被当作资源。上级目录及指向目录外的符号链接当前明确拒绝；57 对基础矩阵及带图往返通过，其他复杂语法仍需验收。

动图转视频：合成 GIF、APNG、WebP 动图到 MP4、MOV、M4V、MKV、WebM、AVI、FLV 共 21 组检查两帧颜色与基本时序；GIF→WebM 合成透明区域通过检查。依赖 FFmpeg；其他容器的透明支持、复杂时序和真实素材仍需验收。

多音轨音频：修复默认只输出一条音轨的问题。合成双音轨 MKA 转 M4A、OGG、OPUS 后，两条音轨均可解码；MP3、WAV、FLAC、AIFF、CAF 容器无法直接容纳多轨时，会将各音轨分别输出到新文件夹；合成样本验证每条音轨的频率、重名保护和原文件保留。56 对单音轨转换回归通过。轨道名称、复杂编码及真实素材仍需验收。

多音轨浮点精度：对 32 位及 64 位浮点 MKA 双音轨，以超出 ±1 的合成信号分别转换到 WAV、AIFF、CAF，逐样本读回与源文件一致；转 FLAC 时提示精度限制。单音轨浮点与 56 对音频格式回归通过。混合编码、真实录音和极大文件仍需进一步审查。
